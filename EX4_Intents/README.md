# 🔐 Login App – SharedPreferences & Intent Demo

A simple Android application developed in **Kotlin** that demonstrates how to:

- Create a Login Screen
- Save user password using SharedPreferences
- Pass the username to another Activity using Intent
- Display the saved information on the Welcome Screen

---

## 📱 Features

- User-friendly Login Screen
- Username and Password input fields
- Password stored using SharedPreferences
- Username passed to another Activity using Intent
- Welcome screen displaying the username and saved password
- Modern UI with gradient background and CardView

---

## 🛠️ Technologies Used

- Kotlin
- Android Studio
- XML
- SharedPreferences
- Intent
- Material Design Components
