# Experiment 5 – Android Notification Application

## 📱 NotifyApp

### Experiment Objective

To create an Android application that demonstrates how to display notifications using Android Studio and Kotlin.

The application, **NotifyApp**, demonstrates the basic implementation of Android notifications. When the user interacts with the application, a notification is generated and displayed in the device/emulator notification panel.

---

## 🎯 Aim

To develop an Android application that displays notifications and understand the concepts of:

* Android Notifications
* Notification Channels
* Notification Manager
* PendingIntent
* Notification permissions
* User interaction with notifications

---

## 📝 Experiment Description

Notifications are an important feature of Android applications. They allow an application to provide information, alerts, reminders, or updates to users even when the application is not currently being used.

In this experiment, **NotifyApp** is developed using **Android Studio and Kotlin**. The application creates a notification channel and uses Android's `NotificationManager` to display a notification.

When the user clicks the notification button, NotifyApp generates a notification containing a title and message. The notification can then be viewed from the device's notification panel.

# 🔔 Concepts Used

## 1. Notification

A notification is a message displayed by an Android application outside its normal user interface.

Notifications can appear in:

* Notification panel
* Status bar
* Lock screen
* Notification shade

---

## 2. Notification Channel

Starting from Android 8.0 (API level 26), notifications must belong to a notification channel.

The application creates a channel with a unique channel ID and a channel name.

Example:

```kotlin
val channel = NotificationChannel(
    CHANNEL_ID,
    "NotifyApp Notifications",
    NotificationManager.IMPORTANCE_DEFAULT
)
```

---

## 3. NotificationManager

`NotificationManager` is used to manage and display notifications.

Example:

```kotlin
val notificationManager =
    getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager

notificationManager.notify(1, notification)
```

---

## 4. PendingIntent

`PendingIntent` allows the notification to perform an action when the user interacts with it.

For example, clicking a notification can open the application.

---

## 5. POST_NOTIFICATIONS Permission

For applications targeting newer Android versions, notification permission may be required.

The application requests the notification permission before displaying notifications.

# 📄 Important Files

### `MainActivity.kt`

Contains the main application logic.

It is responsible for:

* Creating the notification channel
* Requesting notification permission
* Creating the notification
* Displaying the notification

### `activity_main.xml`

Contains the user interface of the application.

It contains the button used to generate the notification.

### `AndroidManifest.xml`

Contains application configuration and required permissions.

For notifications on newer Android versions, the following permission is used:

xml
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />

### `build.gradle.kts`

Contains project dependencies and Android configuration.
